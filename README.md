## Зачем создан этот проект

Раньше для удалённой работы со смартфона приходилось использовать официальный облачный веб-релей ZCode (`zcode.z.ai`). В реальной работе с телефона он доставлял массу неудобств:
* Постоянные задержки облачного релея и долгое переподключение с экраном спаривания (pairing) при каждом сворачивании или выгрузке вкладки из памяти.
* Неприятные скачки и дерганье скролла в диалогах, усиливающиеся по мере роста сессии.
* Урезанный по сравнению с десктопом интерфейс и закрытый минифицированный бандл, не позволявший ничего исправить.

**В этом проекте полноценная ПК-версия ZCode отвязана от облака и адаптирована под экраны смартфонов.** Это не урезанный мобильный клиент, а полнофункциональный десктопный интерфейс, развёрнутый локально и оптимизированный для комфортного тач-управления.

## Главные результаты

### 1. Работа вне облака ZCode (Self-Hosted LAN)
Прямое локальное соединение смартфона с сервером на ПК по домашней сети (~1 мс). 
* Полный отказ от внешнего релея `zcode.z.ai`.
* Скорость восстановления сессии после сворачивания или выгрузки PWA из памяти возросла многократно: исчез экран ожидания спаривания (pairing), связь восстанавливается мгновенно по локальному WebSocket.

### 2. Стабильный скролл без скачков в длинных сессиях
Полностью устранена проблема дерганья и произвольных прыжков ленты сообщений:
* Чат плавно скроллится даже в огромных диалогах с десятками вызовов инструментов.
* Задействован аппаратный momentum-скролл iOS (`-webkit-overflow-scrolling: touch`), изолированы стили строк и расширен буфер предзагрузки виртуализации.

### 3. Оптимизация скорости и подгрузки
Интерфейс стал значительно отзывчивее:
* Устранены задержки и зависания при наборе текста и редактировании слов в Safari (дебаунс черновиков, отвязка от тяжелых ререндеров).
* Ускорены переходы между сессиями, открытие меню и переключение проектов.

### 4. Информативный десктопный UI на телефоне
В отличие от упрощённых веб-интерфейсов, сохранены все возможности взрослой ПК-версии:
* Дерево задач, подробные диффы, вывод терминала, статусы и ошибки инструментов.
* Тяжелые панели не сплющивают экран пополам, а элегантно открываются в виде быстрых выезжающих шторок (drawers) поверх диалога.

### 5. 100% Русская локализация
* Полный перевод интерфейса (5 472 строки) с единым инженерным глоссарием.
* Кнопка быстрого переключения языка («Ру») в подвале сайдбара.

## Связка с десктопным приложением (Handoff ПК ↔ Смартфон)

Десктопная программа `ZCode.exe` и локальный веб-сервер используют **одну и ту же общую папку данных**: `~/.zcode` (в Windows: `C:\Users\<Имя>\.zcode`).

* **Если у вас уже установлен оригинальный ZCode на ПК:**  
  Вам не нужно ничего переносить, копировать или настраивать заново. Веб-сервер автоматически видит все ваши настроенные модели, API-ключи, память, расширения и историю бесед.
* **Если вы устанавливаете ZCode с нуля:**
  * *Только веб и мобильный PWA:* Сам `.exe` не обязателен — пакет `install.sh` даёт полноценную автономную систему. На ПК этот интерфейс можно открыть в браузере или установить в отдельное окно как Desktop PWA (без рамок браузера).
  * *С нативным приложением ZCode.exe:* Установите официальный установщик ZCode с сайта разработчиков или соберите его из исходников (`pnpm dev:desktop`). Общая база подхватится автоматически.

## Дополнительные полезные доработки

* 🔔 **Фоновые уведомления через ntfy:** сервер шлёт push-уведомление на телефон при завершении или ошибке задачи по обычному HTTP (без необходимости держать VPN или SSL-сертификаты).
* ⌨️ **Умный фокус клавиатуры:** экранная клавиатура открывается *только по тапу в поле ввода*, а не вылетает автоматически при каждом переходе между чатами.
* 📎 **Вложения по Wi-Fi:** фото и файлы стабильно прикрепляются по локальному HTTP (встроен JS-фолбэк SHA-256 в обход ограничений WebCrypto).
* 📁 **Мульти-проектность:** сервер поддерживает несколько рабочих каталогов одновременно (`dir1;dir2`), а общие задачи выведены отдельным проектом.
* 🎯 **Сохранение выбранной модели:** последняя выбранная модель запоминается глобально и не сбрасывается при смене проекта.
* 🔒 **Фиксация viewport:** устранён «резиновый» отскок страницы iOS за экран и случайный зум полей ввода.
* 🔌 **Стабильный запуск MCP:** устранена гонка старта медленных MCP-серверов (`collectLateArrivals`).

## Быстрый старт

### Установка готового пакета в одну команду

```bash
curl -fsSL https://github.com/v9n9yphb67-ui/ZCode/releases/download/v3.14.0-web/install.sh | sh
```

Запуск сервера в локальной сети:
```bash
zcode --web --host 0.0.0.0 --port 3040
```

Сервер выведет адрес для подключения:
```
http://192.168.x.x:3040/?token=YOUR_TOKEN
```

### Добавление на домашний экран (PWA)

1. Откройте выданную ссылку в **Safari на iPhone** (или Chrome на Android).
2. Нажмите **Поделиться** -> **На экран «Домой»**.
3. Запустите приложение с иконки — оно работает в полноэкранном автономном режиме.

### Подключение нескольких рабочих папок (Multi-Workspace)

Сервер поддерживает одновременную работу с несколькими проектами через разделение путей символом `;`:

```bash
# Через флаг --workspace:
zcode --web --host 0.0.0.0 --port 3040 --workspace "/путь/к/проекту1;/путь/к/проекту2"

# Либо через переменную окружения ZCODE_SERVER_WORKSPACE:
export ZCODE_SERVER_WORKSPACE="/путь/к/проекту1;/путь/к/проекту2"
zcode --web --host 0.0.0.0 --port 3040
```

В сайдбаре мобильного интерфейса все указанные проекты появятся отдельными строками, позволяя переключаться между ними без перезапуска сервера.

## Безопасность

* Сервер предназначен для работы в защищённой домашней сети Wi-Fi или через частный VPN.
* Не открывайте порт 3040 в публичный интернет без HTTPS-шифрования и обратного прокси-сервера.
